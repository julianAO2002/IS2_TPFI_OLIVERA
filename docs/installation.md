# Installation

## Stable release

To install tpfi, run this command in your terminal:

```sh
uv add tpfi
```

Or if you prefer to use `pip`:

```sh
pip install tpfi
```

## From source

The source files for tpfi can be downloaded from the [Github repo](https://github.com/julianAO2002/tpfi).

You can either clone the public repository:

```sh
git clone https://github.com/julianAO2002/tpfi
```

Or download the [tarball](https://github.com/julianAO2002/tpfi/tarball/main):

```sh
curl -OJL https://github.com/julianAO2002/tpfi/tarball/main
```

Once you have a copy of the source, you can install it with:

```sh
cd tpfi
uv sync
```
